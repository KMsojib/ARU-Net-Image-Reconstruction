# Reproducibility Guide

This document explains how to reproduce the training and evaluation
pipeline described in this repository, and is explicit about what can and
cannot currently be reproduced exactly, given what was provided (thesis
PDF + notebook, no raw dataset, no trained weights, no results CSVs).

## 1. Environment

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Tested against the package versions pinned in `requirements.txt`. A CUDA-
capable GPU is recommended (thesis Sec. 3.6, Table 3.1: "Hardware: GPU");
CPU execution works but will be substantially slower, especially with the
VGG16 perceptual loss term enabled.

## 2. Data

Follow `data/README.md` to place your own clean/distorted image pairs
under `data/clean/` and `data/distorted/<dataset_name>/`. No dataset is
bundled with this repository.

## 3. Configuration

All hyperparameters live in `configs/config.py`. Defaults match the values
**actually executed** in the notebook's `__main__` block (not
necessarily the thesis's Table 3.1, where the two disagree -- see the
Research Implementation Audit in the top-level README).

Key defaults:

- `epochs = 150`
- `learning_rate = 1e-4` (Adam)
- `batch_size_train = 4`, `batch_size_eval = 1`
- `lr_scheduler_step_size = 15`, `lr_scheduler_gamma = 0.5`
- `early_stopping_patience = 20`
- `train_fraction = 0.8`, `val_fraction = 0.1` (remaining 0.1 -> test)
- `split_seed = 42`

## 4. Random seeds

`src/utils.set_seed(42)` fixes `random`, `numpy`, and `torch` (CPU + all
CUDA devices) seeds, matching thesis Sec. 3.6 ("Random seeds are fixed to
ensure reproducibility"). Note that the notebook's `ImagePairDataset`
additionally draws a *fresh* random seed per `__getitem__` call
(`np.random.randint(2147483647)`) purely to keep paired
distorted/clean augmentations spatially aligned -- this per-sample seed is
not itself meant to be fixed across runs, and is preserved as-is.

Exact bit-for-bit reproducibility across machines is not guaranteed
(standard PyTorch/CUDA non-determinism caveats apply, especially with
mixed precision enabled).

## 5. Training

```bash
python scripts/train.py --dataset-name Noise_Multiply_Strong --epochs 150
```

Outputs:
- `results/reconstructions/<dataset_name>/training_validation_metrics.csv`
  -- per-epoch train/val loss, PSNR, SSIM.
- `results/reconstructions/<dataset_name>/training_results.json` -- loss
  history for plotting.
- `checkpoints/<dataset_name>_AttentionResidualUNet_final.pth` -- final
  model weights (only the final epoch is saved; see
  `checkpoints/README.md`).

## 6. Evaluation

```bash
python scripts/evaluate.py \
    --checkpoint checkpoints/Noise_Multiply_Strong_AttentionResidualUNet_final.pth \
    --dataset-name Noise_Multiply_Strong \
    --split test
```

Outputs per-image PSNR/SSIM (leaf-masked with global fallback, see
`docs/methodology.md`) to `results/metrics/test/eval_metrics.csv`, plus
reconstructed images.

## 7. Visualization

```bash
# Qualitative Distorted | Reconstruction | Ground Truth panels
python scripts/visualize.py samples \
    --checkpoint checkpoints/Noise_Multiply_Strong_AttentionResidualUNet_final.pth \
    --dataset-name Noise_Multiply_Strong --num-samples 5

# Training loss + LR curve
python scripts/visualize.py curves \
    --results-json results/reconstructions/Noise_Multiply_Strong/training_results.json
```

## 8. What is NOT reproducible from the materials provided

Being transparent about the limits of this repository:

- **The exact 103-image dataset and its Roboflow/COCO disease
  annotations** were not included in either the thesis PDF or the
  notebook upload, so they cannot be redistributed or regenerated here.
- **The mask-guided degradation generation script** (`I_d = M*I +
  (1-M)*D(I)`, thesis Sec. 3.1.7.1) does not appear as executable code in
  the supplied notebook -- only the *consumption* of already-degraded
  folders is implemented.
- **No trained checkpoint, results CSV, or raw figure data** was supplied,
  so the exact numbers in thesis Tables 4.1/4.2 cannot be independently
  regenerated by this repository; they are reproduced as reported
  values in the README, clearly attributed to the thesis.
- **Early stopping**, as literally written in the notebook's `__main__`
  call (`patience=20` passed to a `train()` that doesn't accept it), would
  not run. This repository implements the early-stopping behavior the
  thesis describes so the pipeline is actually executable end-to-end (see
  `src/train.py` docstring).

## 9. Software versions used during authoring

The notebook's dependency-install cell (`pip install kornia torchmetrics
scikit-image tqdm lpips torchviz graphviz ...`) does not pin any versions,
so exact original library versions are unknown. `requirements.txt` in this
repository specifies reasonable minimum versions compatible with the code
as ported; pin exact versions yourself if bit-for-bit numerical
reproduction across environments is required.
